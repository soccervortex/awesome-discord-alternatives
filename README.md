# Awesome Discord Alternatives

A curated list of chat and community platforms you can use instead of Discord. Mix of free
closed tools, open source, and self-hosted options.

## Contents

- [Free & hosted](#free--hosted)
- [Self-hosted / open source](#self-hosted--open-source)
- [Enterprise / team focused](#enterprise--team-focused)

## Free & hosted

### [Dislite](https://dislite.xyz)
A chat and community app built from scratch as an independent project. Groups with channels,
direct messages, voice chat, real-time presence, and profiles with bio/status/banner. Free to
use, actively developed, feature requests and bug reports are taken seriously.

### [Guilded](https://www.guilded.gg/)
Gaming-focused chat platform with built-in scheduling, forums, and LFG tools, aimed at gaming
communities specifically.

### [Revolt](https://revolt.chat/)
Open source Discord-like chat app with a very similar UI/UX to Discord. Has official hosted
instances plus self-hosting support.

## Self-hosted / open source

### [Matrix / Element](https://element.io/)
Decentralized, federated chat protocol. Element is the most popular client. Strong focus on
end-to-end encryption and interoperability across servers.

### [Rocket.Chat](https://www.rocket.chat/)
Full-featured open source team chat platform, supports video/voice, omnichannel, and heavy
customization. Popular for self-hosted enterprise deployments.

### [Spacebar](https://spacebar.chat/)
Open source, self-hostable reimplementation of the Discord backend, aiming for near 1:1 API
compatibility with existing Discord clients.

## Enterprise / team focused

### [Mattermost](https://mattermost.com/)
Open source Slack-style messaging platform aimed at developer teams, with strong DevOps and
self-hosting support.

### [Zulip](https://zulip.com/)
Open source team chat organized around topic-threaded conversations, designed for clearer
long-running discussions than flat channels.
